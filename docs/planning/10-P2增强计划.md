# 10 - P2 增强计划

> 来源：P2-01~05 文档 | 状态：📋 待启动

## P2 目标

在 P1（产品化）基础上增强为**智能化平台**。

## 能力清单

| 编号 | 模块 | 能力 | 说明 |
|------|------|------|------|
| P2-1 | 数据摄入 | 外部数据源订阅 (RSS/API/Webhook) | `kb_data_sources` + `kb_raw_entries` 表已建 |
| P2-2 | 数据处理 | LLM 清洗管道 | 原始数据 → 去噪摘要 → 切片 → 入库 |
| P2-3 | 定时任务 | Cron 调度摄入 | APScheduler / Celery |
| P2-4 | 反馈学习 | 问答点赞/踩 → 检索排序优化 | `kb_feedback` 表已建 |
| P2-5 | 检索增强 | BCE Reranker 精排 | 粗排 HNSW Top-50 + 精排交叉编码器 Top-5 |
| P2-6 | 知识运营 | 知识卡片分享 + 日报生成 | 前端 KnowledgeCard 组件已有基础 |

## 核心数据流

```
┌─────────────┐    ┌──────────────┐    ┌─────────────┐    ┌──────────┐
│ Cron 调度器  │──→│ 数据源拉取    │──→│ 原始暂存      │──→│ LLM 清洗 │
│ (定时触发)   │    │ RSS/API/WEB  │    │ kb_raw_entries│   │ 去噪摘要  │
└─────────────┘    └──────────────┘    └─────────────┘    └────┬─────┘
                                                               │
                                          ┌────────────────────┘
                                          ▼
                                   ┌──────────────┐    ┌──────────┐
                                   │ Chunk+Embed  │──→│ pgvector │
                                   └──────────────┘    └──────────┘
```

## 反馈学习闭环

```
用户提问 → RAG 回答
              │
              ▼
         用户评价 (1-5 分)
              │
         ┌────┴────┐
         ▼         ▼
    高分 → 提升对应 chunk 权重
    低分 → 降低权重 / 标记待审核
```

## 数据库依赖（P1 已建表）

| 表 | 用途 | 启用阶段 |
|----|------|---------|
| `kb_data_sources` | 外部数据源定义 | P2 |
| `kb_raw_entries` | 原始数据暂存 + 清洗 | P2 |
| `kb_feedback` | 问答反馈评分 | P2 |

## 实施顺序

```
Phase A: 定时任务基础设施
  └── APScheduler + Cron 表达式解析

Phase B: 数据摄入管道
  ├── RSS 解析器
  ├── API 拉取器
  └── LLM 清洗服务

Phase C: 反馈学习
  └── 评分 → 检索权重调整

Phase D: 内容运营
  └── 知识卡片 / 日报
```
