## 1. 项目简介

mindvaults 是一个开源、隐私至上的**本地 RAG 知识库问答系统**。把 PDF、Markdown、Word 丢进来，搭配本地大模型，即刻拥有专属 AI 问答引擎。离线索引、双屏溯源、零数据外泄。

### 核心特性

- **数据主权**：100% 本地运行，零外网上传，支持 Air-gapped 断网部署
- **引用溯源**：每个回答论断精确关联到源文件页码和相似度分数
- **思维可视化**：实时展示 RAG 检索全链路（意图识别 → 向量检索 → 匹配打分 → 大模型推理）
- **多模型适配**：支持本地 Ollama 和云端 API（DeepSeek / OpenAI 兼容）一键切换
- **开源自托管**：Docker Compose 一键部署，无厂商锁定

### 技术栈

| 层 | 技术 |
|----|------|
| 前端 | Next.js 14 (App Router) + TypeScript + Tailwind CSS |
| 后端 | FastAPI (Python 3.12) + SSE 流式 |
| 向量库 | PostgreSQL + pgvector (HNSW 索引) |
| 缓存 | Redis |
| 大模型 | Ollama (本地) / OpenAI 兼容 API (云端) |
| Embedding | BGE-M3 / BGE-large-zh-v1.5 (1024 维) |
| 部署 | Docker Compose + nginx |

## 2. 项目背景

在企业办公、研发运维场景中，大量私有知识数据（规章制度、业务手册、研发文档、接口规范等）分散存储，传统查询依赖人工翻阅、效率低、沉淀困难。

通用大模型存在三大核心问题：**知识滞后、无法适配私有业务、数据隐私泄露**。

mindvaults 实现纯本地私有化 RAG 知识库，所有文档解析、向量化、检索、推理均在本机完成，零外网依赖。
