# 11 - 品牌与视觉设计

> 来源：BRANDING_GUIDE.md + design_proposal.md | 状态：✅ 当前

## 1. 品牌定位

**Security-First AI RAG Knowledge Base** — 隐私优先的安全 RAG 知识库。

核心理念：**让 RAG 不再是黑盒**。将 AI 搜索、匹配、分析、推理的每一个步骤可视透明。

## 2. 色系

| 颜色 | 色值 | 用途 |
|------|------|------|
| **Deep Slate** | `#0f172a` | 侧边栏主背景，"金库"底色 |
| **Cyber Indigo** | `#4f46e5` / `#6366f1` | 主按钮、激活态焦点、主色调 |
| **Neon Cyan** | `#22d3ee` | 神经网络连线、活跃状态、引用指针 |
| **Active Mint** | `#10b981` | 本地文件状态灯（已同步、安全）、系统健康 |
| **Slate 800** | `#1e293b` | 边框、深色卡片 |
| **Slate 50** | `#f8fafc` | 页面主背景 |

## 3. UI 设计原则

- **Glass Box Vault（透明金库）**：推理过程完全展开可见
- **Flat Glass（平板玻璃）**：1px 精致边框替代厚重阴影
- **Neon Accents（霓虹高亮）**：用颜色传递系统状态（绿=安全、蓝=检索中、紫=推理中）
- **Citation First（引用优先）**：每个论断都可追溯到原文

## 4. 排版

- 字体：系统默认 `font-sans`，中文优先
- 代码：`font-mono`
- 字号体系：`text-[10px]`（微标注）/ `text-xs`（正文）/ `text-sm`（标题）/ `text-base`（主标题）
- 圆角：统一 `rounded-xl` (12px) / `rounded-2xl` (16px)

## 5. 关键 UI 元素

### 推理过程面板
```
┌─ 🧠 RAG 推理过程 ───────── 收起 ▲ ─┐
│ ● 正在分析问题意图...              │ ← intent (紫)
│ ● 正在检索本地向量数据库...         │ ← retrieval (蓝)
│ ● -> [1] doc.pdf (匹配度: 94.6%)   │ ← matching (绿)
│ ● 正在调用大模型推理...             │ ← generating (紫)
└────────────────────────────────────┘
```

### 引用溯源
- **CitationBadge**：答案中 `[1]` 角标，悬停浮窗预览原文
- **CitationCard**：底部引用来源卡片（文件名 + 页码 + 相似度）
- **CitationDrawer**：右侧滑出原文溯源面板

### 状态指示
- 绿色圆点 + 脉冲动画：系统在线、索引成功
- 蓝色：检索进行中
- 紫色：大模型推理中
