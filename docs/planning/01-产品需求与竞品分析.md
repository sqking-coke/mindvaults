# 01 - 产品需求与竞品分析

> 来源：设计文档 v1.1 第 2-3 章 | 状态：✅ 当前

## 1. 功能需求

### 1.1 本地文档导入与解析

- 支持 PDF、Word、TXT、Markdown、CSV、JSON、HTML 等主流格式批量上传
- 自动解析文档内容、过滤空白内容、清洗无效格式
- 支持单文件上传、批量文件夹导入、Obsidian Vault 导入
- 支持文档新增、删除、更新、禁用，实现知识库动态维护

### 1.2 文本切片与预处理

- 固定大小切片（可配置 chunk_size / chunk_overlap）
- 保留文档元数据（文件名、页码、章节）
- 文本清洗：去噪、去重、UTF-8 规范化、空段落过滤

### 1.3 向量化与语义检索

- BGE-M3 1024 维 Embedding
- pgvector HNSW 索引高性能检索（<50ms）
- 余弦相似度评分，默认阈值 0.35
- 粗排（HNSW Top-50）+ 精排（BCE Reranker Top-5）两级流水线

### 1.4 智能问答

- RAG 增强生成：检索片段 → 拼 Prompt → LLM 流式输出
- 多轮对话上下文注入（最近 5 轮）
- SSE 流式响应：progress（推理过程）/ token（打字机）/ done（引用溯源）/ error
- 意图识别：knowledge_qa / document_lookup / chitchat

### 1.5 知识库管理

- 多知识库创建、更新、删除
- 文档归属知识库，检索限定 KB 范围
- 知识库级 RAG 配置（独立的 chunk_size、top_k、阈值等）

### 1.6 问答复盘与统计

- 历史问答记录查询、按会话查看
- 高频问题 Top-N 统计
- 待补充问题识别（检索命中率低的提问）

## 2. 竞品差异化定位

| 维度 | Dify / FastGPT / AnythingLLM | mindvaults |
|------|------|------|
| **数据隐私** | 依赖外部 API / 云向量库，部分文档需上传第三方 | **纯本地闭环**，零外网上传，数据不出内网 |
| **知识更新** | 手动上传文档触发入库 | **主动订阅 + 自动学习**（P2-P3），定时抓取 → 清洗 → 入库 |
| **内容运营** | 无 | **知识卡片 + 日报 + 公众号适配**，知识可对外分享传播 |
| **多场景覆盖** | 单一企业问答 | **企业团队 + 个人技能成长双模式** |
| **质量控制** | 无审核机制 | **沙盒审核 + 相似度去重** |
| **引用溯源** | 基础引用文本展示 | **Hover Popover 悬浮预览 + 双屏联动 + PDF 页码定位** |
| **部署复杂度** | 依赖云服务注册/付费 | **Docker Compose 一键部署**，本地 Ollama 开箱即用 |
| **推理透明** | 黑盒问答 | **SSE progress 全链路透传**：意图→检索→匹配→生成 |

## 3. 用户场景

### 场景 A：企业研发团队

> 研发文档（API 规范、架构设计、Postmortem）散落在 Git / 飞书 / 本地。mindvaults 统一导入后，新人问"微服务间怎么通信？"秒级得到带原文引用的答案。

### 场景 B：个人知识管理

> 用 Obsidian 记了 500+ 篇笔记，mindvaults 导入 Vault 后直接对笔记提问："我关于注意力机制的所有笔记"，检索出 5 篇相关笔记并摘要。

### 场景 C：安全合规场景

> 金融/医疗企业的合规文档不能上传任何云服务。mindvaults 部署在内网物理隔离服务器，Ollama 本地推理，所有数据不出机房。
