## 2. 状态管理

### Context 核心状态

```typescript
interface mindvaultssContextType {
  // 会话
  conversations: Conversation[];
  activeConversationId: string | null;
  addConversation(): string;
  deleteConversation(id: string): void;
  renameConversation(id: string, title: string): void;
  sendMessage(content: string): void;
  isGenerating: boolean;

  // 知识库
  knowledgeBases: KnowledgeBase[];
  activeKbId: string | null;
  addKnowledgeBase(name: string, description: string): void;
  deleteKnowledgeBase(id: string): void;

  // 文档
  documents: DocumentRecord[];
  uploadDocuments(kbId: string, files: File[]): void;
  deleteDocument(docId: string): void;
  reindexDocument(docId: string): Promise<void>;

  // 系统配置
  systemConfig: SystemConfig | null;
  ollamaModels: string[];
  updateSystemConfig(config: SystemConfigRequest): Promise<boolean>;

  // Vault
  importVault(path: string): Promise<VaultImportResponse>;
  uploadVault(files: File[]): Promise<VaultImportResponse>;

  // 🆕 监控
  dashboardData: DashboardData | null;
  alerts: Alert[];
  fetchDashboard(): Promise<void>;
  resolveAlert(eventId: number): Promise<void>;

  // 🆕 知识沉淀
  insights: Insight[];
  pendingInsightCount: number;
  fetchInsights(kbId: number, status: string): Promise<void>;
  reviewInsight(id: number, action: 'approve' | 'reject'): Promise<void>;

  // 🆕 概念术语
  concepts: Concept[];
  fetchConcepts(kbId: number): Promise<void>;
  updateConcept(id: number, data: ConceptUpdate): Promise<void>;

  // 🆕 健康治理
  healthReports: HealthReport[];
  latestHealthReport: HealthReport | null;
  triggerHealthScan(kbId: number): Promise<void>;
  resolveHealthIssue(reportId: number): Promise<void>;
}
```

### 数据流

```
用户操作 → Context Action → ragService API 调用 → 后端
                                                       ↓
用户看到 ← React 重渲染 ← Context State 更新 ← API 响应
```

## 5. 关键交互

### 推理过程面板
- assistant 消息接收 `progress` SSE 事件后实时展示
- `round_key` 绑定 Redis 缓存，刷新页面可回放历史推理步骤
- 默认展开，点击可折叠
- 按阶段着色：意图(紫) / 路由(橙) / 检索(蓝) / 匹配(绿) / 生成(紫)
- 每条显示 `elapsed_ms` 耗时

### 大模型快速切换
- 聊天页头部 "运行智核" 下拉框
- Ollama 模式：列出本地已下载模型
- 云端模式：预设列表 + 自定义模型加入

### 知识库切换
- 聊天页顶部 KB 选择器下拉框
- 支持「自动」模式（触发智能路由）或手动指定 KB
- 侧边栏导航切换 KB 时触发：
  - 重新加载文档列表 (`kb_id` 过滤)
  - 重新加载会话列表 (`kb_id` 过滤)
  - 切换 `activeKbId`

### 概念 Hover 卡片 🆕
- 回答/文档中术语显示下划线样式
- hover 弹出卡片：术语名 + 定义摘要 + 相关概念链接
- 点击跳转到概念管理页详情

### 监控看板 🆕
- 暗色主题（bg-slate-900），独立页面
- 顶部折叠告警条：显示活跃告警数，展开后单条 ✕ 解除
- 8 指标卡：今日路由 / 质心命中率 / LLM 路由率 / 降级率 / LLM 调用 / 平均耗时 / Token / 可用率
- Recharts 图表：路由趋势面积图 / Token 堆叠柱状图 / 耗时分桶直方图 / KB 热度横向进度条
- 系统事件面板 + 提炼概念统计卡
- 告警规则配置区（可折叠）

## 6. 样式体系

- **框架**: Tailwind CSS + 自定义 `landing.css`
- **色系**: Deep Slate (#0f172a) / Cyber Indigo (#4f46e5) / Neon Cyan (#22d3ee) / Active Mint (#10b981)
- **圆角**: 统一 `rounded-xl` / `rounded-2xl`
- **阴影**: 低饱和度 `shadow-sm` / `shadow-indigo-500/10`
- **字体**: `font-sans` (系统默认，中文优先)
