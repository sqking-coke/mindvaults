## 2. 状态管理

### Context 核心状态

```typescript
interface MindVaultsContextType {
  // 会话
  conversations: Conversation[];
  activeConversationId: string | null;
  addConversation(): string;
  deleteConversation(id: string): void;
  renameConversation(id: string, title: string): void;
  sendMessage(content: string): void;
  isGenerating: boolean;

  // 知识库
  knowledgeBases: KnowledgeBase[];
  activeKbId: string | null;
  addKnowledgeBase(name: string, description: string): void;
  deleteKnowledgeBase(id: string): void;

  // 文档
  documents: DocumentRecord[];
  uploadDocuments(kbId: string, files: File[]): void;
  deleteDocument(docId: string): void;
  reindexDocument(docId: string): Promise<void>;

  // 系统配置
  systemConfig: SystemConfig | null;
  ollamaModels: string[];
  updateSystemConfig(config: SystemConfigRequest): Promise<boolean>;

  // Vault
  importVault(path: string): Promise<VaultImportResponse>;
  uploadVault(files: File[]): Promise<VaultImportResponse>;
}
```

### 数据流

```
用户操作 → Context Action → ragService API 调用 → 后端
                                                       ↓
用户看到 ← React 重渲染 ← Context State 更新 ← API 响应
```

## 4. 关键交互

### 推理过程面板
- assistant 消息接收 `progress` SSE 事件后实时展示
- 默认展开，点击可折叠
- 按阶段着色：意图(紫) / 检索(蓝) / 匹配(绿) / 生成(紫)
- 每条显示 `elapsed_ms` 耗时

### 大模型快速切换
- 聊天页头部 "运行智核" 下拉框
- Ollama 模式：列出本地已下载模型
- 云端模式：预设列表 + 自定义模型加入

### 知识库切换
- 侧边栏导航切换 KB 时触发：
  - 重新加载文档列表 (`kb_id` 过滤)
  - 重新加载会话列表 (`kb_id` 过滤)
  - 切换 `activeKbId`

## 5. 样式体系

- **框架**: Tailwind CSS + 自定义 `landing.css`
- **色系**: Deep Slate (#0f172a) / Cyber Indigo (#4f46e5) / Neon Cyan (#22d3ee) / Active Mint (#10b981)
- **圆角**: 统一 `rounded-xl` / `rounded-2xl`
- **阴影**: 低饱和度 `shadow-sm` / `shadow-indigo-500/10`
- **字体**: `font-sans` (系统默认，中文优先)
