# 统一异常处理规范

> 版本：v1.0 | 状态：⚠️ 部分实施 | 适用范围：backend + frontend

## 1. 设计目标

- **统一错误码**：全项目唯一，前后端一致
- **结构化响应**：错误信息携带 trace_id、错误码、详情
- **异常分层**：业务异常 / 系统异常 / 校验异常，各司其职
- **日志联动**：异常自动携带 trace_id，写入日志
- **前端友好**：错误码对应中文提示，用户看得懂

## 2. 异常体系

```
AppException (base)
  ├── BusinessException (code 1xxx-4xxx)
  │     ├── DocNotFoundException        2001  文档不存在
  │     ├── DocFormatUnsupportedError    2002  格式不支持
  │     ├── DocSizeExceededError         2003  文档过大
  │     ├── DocStatusInvalidError        2004  状态无效
  │     ├── SessionNotFoundError         3001  会话不存在
  │     ├── KbNotFoundError              6001  知识库不存在
  │     └── RetrievalNoHitsError         4001  检索无结果
  │
  ├── ValidationException (code 1xxx)
  │     └── BadRequestError              1001  参数校验失败
  │
  └── SystemException (code 5xxx-9xxx)
        ├── LLMCallFailedError           5001  大模型调用失败
        ├── EmbeddingUnavailableError    5002  Embedding 不可用
        ├── DatabaseError                8001  数据库异常
        ├── RedisError                   8002  Redis 异常
        └── InternalError                9001  服务内部错误
```

## 3. 错误码规范

## 5. Base 异常类设计

```python
# app/core/exceptions.py

import json
from typing import Any
from fastapi import Request
from fastapi.responses import JSONResponse
from loguru import logger


class AppException(Exception):
    """基础业务异常。"""
    status_code: int = 400

    def __init__(
        self,
        code: int,
        message: str,
        detail: Any = None,
        status_code: int | None = None,
    ):
        self.code = code
        self.message = message
        self.detail = detail
        if status_code is not None:
            self.status_code = status_code

    def to_dict(self) -> dict:
        result = {"code": self.code, "message": self.message}
        if self.detail is not None:
            result["detail"] = self.detail
        return result


class ValidationException(AppException):
    """校验异常（支持多字段错误）。"""
    def __init__(self, errors: list[dict] | str):
        if isinstance(errors, str):
            errors = [{"message": errors}]
        super().__init__(code=1002, message="字段校验不通过", detail=errors, status_code=422)
```

## 6. 全局异常处理器

```python
# app/core/exceptions.py（追加）

async def app_exception_handler(request: Request, exc: AppException) -> JSONResponse:
    """业务异常 → 结构化响应 + 日志。"""
    trace_id = getattr(request.state, "trace_id", "—")
    body = exc.to_dict()
    body["trace_id"] = trace_id

    # 日志记录（WARNING 级别：预期的业务异常）
    logger.bind(trace_id=trace_id).warning(
        f"business_exception code={exc.code} message=\"{exc.message}\""
    )

    return JSONResponse(status_code=exc.status_code, content=body)


async def validation_exception_handler(request: Request, exc: ValidationException) -> JSONResponse:
    """校验异常 → 422 + 字段详情。"""
    trace_id = getattr(request.state, "trace_id", "—")
    body = exc.to_dict()
    body["trace_id"] = trace_id

    logger.bind(trace_id=trace_id).info(
        f"validation_failed errors={json.dumps(exc.detail, ensure_ascii=False)}"
    )

    return JSONResponse(status_code=422, content=body)


async def unhandled_exception_handler(request: Request, exc: Exception) -> JSONResponse:
    """未捕获异常 → 500 + 日志 ERROR。"""
    trace_id = getattr(request.state, "trace_id", "—")

    # 提取 traceback 最后一行
    tb = exc.__traceback__
    tb_last = ""
    if tb:
        while tb.tb_next:
            tb = tb.tb_next
        tb_last = f"{tb.tb_frame.f_code.co_filename}:{tb.tb_lineno}"

    logger.bind(trace_id=trace_id).error(
        f"unhandled_exception error=\"{exc}\" traceback_last=\"{tb_last}\""
    )

    return JSONResponse(
        status_code=500,
        content={"code": 9001, "message": "服务内部错误", "trace_id": trace_id},
    )
```

## 8. 前端错误处理

### 8.1 错误码映射

```typescript
// src/utils/errorCode.ts
export const ERROR_MESSAGES: Record<number, string> = {
  1001: "请检查输入内容",
  1002: "请检查填写内容",
  2001: "该文档已被删除或不存在",
  2002: "仅支持 PDF、Word、Markdown 和 TXT 格式",
  2003: "文件大小超过限制，请压缩后重试",
  3001: "该对话已被删除",
  4001: "知识库中暂无相关内容，请上传文档后再试",
  5001: "AI 服务暂时不可用，请稍后重试",
  6001: "该知识库已被删除",
  8001: "系统繁忙，请稍后重试",
  9001: "系统异常，请联系管理员",
};

export function getErrorMessage(code: number, fallback?: string): string {
  return ERROR_MESSAGES[code] || fallback || `未知错误 (${code})`;
}
```

### 8.2 API 层拦截

```typescript
// src/services/apiClient.ts — handleResponse 增强
async function handleResponse<T>(res: Response): Promise<T> {
  const json = await res.json();
  if (!res.ok || json.code !== 0) {
    const traceId = res.headers.get("X-Trace-Id") || "";
    const message = getErrorMessage(json.code, json.message);
    throw new ApiError(json.code, message, traceId);
  }
  return json.data;
}
```

## 9. 与日志系统的集成

- `app_exception_handler` → `logger.warning("business_exception ...")`
- `unhandled_exception_handler` → `logger.error("unhandled_exception ...")` + `traceback_last`
- 响应体自动携带 `trace_id`（前端报错时可粘贴定位）
