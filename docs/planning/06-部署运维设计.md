# 06 - 部署运维设计

> 来源：05-数据库与部署设计.md | 状态：✅ 当前

## 1. Docker Compose 拓扑

```
┌─────────────────────────────────────────────────────┐
│                    nginx:80                          │
│  /          → frontend:3000                         │
│  /api/*     → backend:8000  (buffering off for SSE) │
└──────────┬────────────────────┬─────────────────────┘
           │                    │
    ┌──────▼──────┐      ┌──────▼──────┐
    │  frontend   │      │  backend    │
    │  next.js 14 │      │  FastAPI    │
    │  :3000      │──────│  :8000      │
    └─────────────┘      └──────┬──────┘
                                │
              ┌─────────────────┼─────────────────┐
              │                 │                 │
        ┌─────▼─────┐   ┌──────▼──────┐   ┌──────▼──────┐
        │ PostgreSQL │   │   Redis     │   │   Ollama    │
        │ pgvector   │   │   :6379     │   │   :11434    │
        │ :5432      │   │   (缓存)    │   │   (LLM+Emb) │
        └────────────┘   └────────────┘   └─────────────┘
```

## 2. docker-compose.yml（核心服务）

```yaml
services:
  frontend:
    build: { context: ., dockerfile: Dockerfile.frontend }
    ports: ["3000:3000"]
    environment:
      - NEXT_PUBLIC_API_BASE=http://localhost/api/v1
    depends_on: [backend]

  backend:
    build: { context: ./backend, dockerfile: Dockerfile }
    ports: ["8000:8000"]
    environment:
      - DATABASE_URL=postgresql+asyncpg://mindvaults:mindvaults@db:5432/mindvaults
      - REDIS_URL=redis://redis:6379
      - LLM_BASE_URL=http://ollama:11434/v1
    volumes:
      - uploads_data:/app/uploads
      - ./logs:/app/logs
    depends_on:
      db: { condition: service_healthy }
      redis: { condition: service_started }

  db:
    image: pgvector/pgvector:pg16
    environment:
      POSTGRES_DB: mindvaults
      POSTGRES_USER: mindvaults
      POSTGRES_PASSWORD: mindvaults
    volumes: [pgdata:/var/lib/postgresql/data]
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U mindvaults"]
      interval: 5s

  redis:
    image: redis:7-alpine

  ollama:
    image: ollama/ollama:latest
    volumes: [ollama_data:/root/.ollama]

  nginx:
    image: nginx:alpine
    ports: ["80:80"]
    volumes: [./nginx.conf:/etc/nginx/nginx.conf:ro]
    depends_on: [frontend, backend]

volumes:
  pgdata:
  ollama_data:
  uploads_data:
```

## 3. nginx SSE 关键配置

```nginx
location /api/ {
    proxy_pass http://backend:8000;
    proxy_http_version 1.1;
    proxy_buffering off;        # ★ SSE 必须关闭缓冲
    proxy_cache off;
    proxy_read_timeout 300s;    # 长连接超时
}
```

## 4. 本地开发（非 Docker）

```bash
# 后端
cd backend
source venv/bin/activate
pip install -r requirements.txt
alembic upgrade head
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload

# 前端
npm install
npm run dev
```

## 5. 环境变量

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `DATABASE_URL` | `postgresql+asyncpg://...` | 数据库连接 |
| `REDIS_URL` | `redis://localhost:6379` | Redis 缓存 |
| `LLM_PROVIDER` | `ollama` | 大模型提供者 |
| `LLM_BASE_URL` | `http://localhost:11434/v1` | LLM API 地址 |
| `LLM_MODEL` | — | 默认模型代号 |
| `LLM_API_KEY` | — | 云端 API 密钥 |
| `EMBEDDING_MODEL` | `BAAI/bge-large-zh-v1.5` | Embedding 模型 |
| `API_KEY` | `sk-mindvaults-dev` | 后端鉴权密钥 |
| `MAX_UPLOAD_SIZE_MB` | `50` | 文件上传大小限制 |
